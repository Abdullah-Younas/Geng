# GENG

A C++ OpenGL-based graphics engine built to experiment with modern rendering techniques, real-time lighting, and scene management.
This project serves as a sandbox for testing different graphics concepts, shaders, and engine features.

**⚠️ Note: Development is currently paused.**

# ✨ Implemented Features

**Rendering Pipeline**

Modern OpenGL (Core Profile 3.3+)

Depth testing enabled

Model loading (.obj) with transformations

**Lighting System**

Directional Light (adjustable intensity & color)

Point Lights (multiple instances)

Spotlight (camera-attached)

**Fog System**

Adjustable fog density and color

**Skybox**

Cubemap rendering with toggle option

**Camera & Input**

First-person and orbit camera support

Keyboard & mouse input handling

**ImGui Debug Tools**

Real-time control over lighting

Fog settings editor

Background color adjustment

Skybox toggle

# 🛠️ Technologies Used

**C++17**

**OpenGL (GLFW + GLAD)**

**GLM (math library)**

**stb_image (texture loading)**

**Dear ImGui (debug interface)**
